# 근무표 급여계산

알바와 교대근무자의 일정, 월 근무시간, 기본 시급 기준 예상 급여를 한 화면에서 관리하는 Apps-in-Toss WebView 미니앱입니다.

## 포함한 첫 버전

- 오늘 근무와 시급 기준 예상액
- 월간 근무표 직접 입력
- 2교대 / 3교대 / 주주야야휴휴 반복 패턴
- 월 근무시간과 기본 시급 기준 예상 급여
- Apps-in-Toss `Storage`에 기기별 데이터 저장

## 시작하기

```bash
npm install
npx ait init
npm run dev
```

`granite.config.ts`의 `appName`은 현재 콘솔에 등록된 `lotto-ai-picker`로 맞춰 두었습니다. 출시 전에 콘솔의 앱 이름·소개·이미지를 `근무표 급여계산` 서비스에 맞게 수정하고, 이 프로젝트를 새 번들로 업로드하세요.

## 주의

표시 금액은 사용자가 입력한 기본 시급과 근무시간만 계산한 예상치입니다. 주휴수당, 야간·휴일 가산, 세금과 공제는 계약 조건에 따라 달라지므로 첫 버전에서는 자동 계산하지 않습니다.
