# 근무표 급여계산

알바와 교대근무자의 일정, 월 근무시간, 기본 시급 기준 예상 급여를 한 화면에서 관리하는 Apps-in-Toss WebView 미니앱입니다.

## 포함한 첫 버전

- 오늘 근무와 시급 기준 예상액
- 월간 근무표 직접 입력
- 2교대 / 3교대 / 주주야야휴휴 반복 패턴
- 월 근무시간과 기본 시급 기준 예상 급여
- 주휴수당 포함 여부·주 소정근로시간·개근 주 수 설정
- 2026년 기준 4대보험 근로자 부담분 예상 공제
- Apps-in-Toss `Storage`에 기기별 데이터 저장

## 시작하기

```bash
npm install
npx ait init
npm run dev
```

`granite.config.ts`의 `appName`은 현재 콘솔에 등록된 `work-pay`로 맞춰 두었습니다. 출시 전에 콘솔의 앱 이름·소개·이미지를 `근무표 급여계산` 서비스에 맞게 수정하고, 이 프로젝트를 새 번들로 업로드하세요.

## 주의

표시 금액은 예상치입니다. 주휴수당은 사용자가 입력한 주 소정근로시간과 개근 주 수를 토대로 계산하며, 실제 적용 여부는 근로계약·개근·근로관계 지속 여부 등을 확인해야 합니다. 4대보험은 예상 급여를 기준으로 근로자 부담분만 단순 적용합니다. 보수월액·비과세 항목·세금·사업장 신고 내용에 따라 급여명세서와 달라질 수 있습니다.
